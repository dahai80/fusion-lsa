> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the M0 feasibility numbers that gate M1: dense prefill rate curve, dense RULER baselines (accuracy anchor), 950DT training feasibility, MLX LoRA smoke.

**Architecture:** New standalone repo `hsa` (Hierarchical Sparse Attention) at `/Users/dahai/fusion/hsa` — sibling of fusion-lsa. Bench tooling is HTTP-driven against a fusion-mlx server (no in-process model code in M0); 950DT probe is a scripted ssh session through the jump host, results land in the repo as a report.

**Tech Stack:** Python 3.12 (shared fusion venv), httpx, pytest; remote: torch 2.10 + torch_npu 2.10.0.post7 in the 950DT service container (proven Phase 0).

**Spec:** `docs/superpowers/specs/2026-11-08-sparse-prefill-design.md` (in fusion-lsa repo; G1/G2/G5/M0 are the tasks' source of truth).

Colleague may be using it — if busy, record and defer, do not fight for it.
- Success bars from spec: 512k prefill >= 150 tok/s end-to-end; RULER retrieval categories >= 0.99 ratio vs dense (dense baseline = these tasks' output).

## Review Focus

- Chunk-rate sampling must read per-chunk rate from SERVER logs (memcheck lines), not client-side wall/token — client timing includes queueing and lies at depth. Test: mock log with known rates, parser must reproduce them exactly (Task 2).
- Dense RULER at 128k runs a ~40 GB-class prefill — same machine that dies thermally. Every local run must be preceded by a cooling check and followed by a rest interval; the bench script must refuse to start if a previous run is still resident (Task 3).
- The 950DT probe must NOT touch the colleague's Phase-1 state: read-only checks plus a throwaway smoke script in `/mnt/sfs_turbo/dahai/hsa_probe/`, never inside their latent-sparse-attention tree (Task 4).
- LoRA smoke must use the quantized base (4-bit) — bf16 27B LoRA on 128 GB while the default server holds 23 GB risks the exact saturation that panicked the machine (Task 5).
- Every remote command must be non-interactive (ssh BatchMode-style with sshpass or key), so the probe is re-runnable by the executor without a TTY (Task 4).
